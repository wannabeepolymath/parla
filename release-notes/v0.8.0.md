Parla now tells you when AI cleanup isn't running, and fixes the most common reason it stops: an API key Parla saved in your Keychain but can't read back. This release also adds M4A and MP3 import, JSON export for imported audio, and better use of your dictionary words.

## Install

1. Download **Parla-0.8.0.dmg** below.
2. Open it and drag Parla into Applications.
3. Open Parla from Applications.

Runs on Apple silicon and Intel Macs, macOS 13.3 or later.

## If you're upgrading from 0.7.0

Choose **Install Update v0.8.0** in the menu bar menu. Parla downloads the new version, swaps it in and reopens. Microphone and Accessibility permissions carry over.

If the menu bar menu then shows **⚠️ AI cleanup isn't running: Keychain access was denied…**, open **AI Cleanup**, paste your API key and choose **Save**. This happens when a different build of Parla saved the key, because macOS only lets the build that saved a key read it. Parla now keeps a copy of the key it can read, so you only need to do this once.

## New

- **Import Audio** accepts M4A and MP3 files, up to 10 minutes and 20 MB. They're transcribed without timestamps, and **Save a copy and transcribe** doesn't keep them yet; use **Transcribe** for these files.
- **Export JSON…** in Import Audio saves the raw transcript, the model used and, when available, timestamps.
- **The Dictionary** now gives the speech model as many of your words as fit its prompt, highest in the list first, and the Hub shows how many fit once the model is loaded.
- **Check for Updates** now tells you when a new version is available.

## Fixed

- When AI cleanup fails, the pill now shows a warning, **⚠️ Pasted raw text: …**, instead of a checkmark. If the problem is your key or provider settings, it says **check AI Cleanup**, and the menu bar menu keeps a line saying why cleanup isn't running. If cleanup fails three times in a row for the same reason, the menu says that too.
- Choosing **Save** for an API key now works even when the saved key belongs to a different build of Parla. Before, cleanup could fail on every dictation with no way to fix it inside Parla.
- When a dictation produces no text because the microphone sent no sound, the pill names the microphone, for example "No sound from AirPods — in use by another app?". Very short taps no longer show an error.
- **Save a copy and transcribe** no longer stays stuck after you cancel just as transcription finishes. A file that's still in progress, or was interrupted, now says so instead of "Too many saved files".
- Imported files with emoji or unusual characters in their names are saved and shown correctly.

## Building from source

Still supported: `git checkout v0.8.0 && scripts/make-app.sh && open Parla.app`. A build from source can't install updates itself, since it isn't signed with the release's Developer ID, so its menu item opens the release page.
