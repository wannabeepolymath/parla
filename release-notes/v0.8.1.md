Parla now moves your API key into Keychain by itself, even when an older key from a different build of Parla is in the way. You no longer need to paste the key again.

## Install

1. Download **Parla-0.8.1.dmg** below.
2. Open it and drag Parla into Applications.
3. Open Parla from Applications.

Runs on Apple silicon and Intel Macs, macOS 13.3 or later.

## If you're upgrading

Choose **Install Update v0.8.1** in the menu bar menu. Parla downloads the new version, swaps it in and reopens. Microphone and Accessibility permissions carry over.

If AI cleanup stopped because of **Keychain access was denied**, it starts working again on your next dictation, or as soon as you open **AI Cleanup**.

## Fixed

- **Refresh** in AI Cleanup now works when the key in your Keychain was saved by a different build of Parla. Parla moves the key from its settings file into its own Keychain entry, so cleanup starts working again with no pasting. Before, Refresh showed the same error every time.
- The line under the API key field now says **Keychain access was denied** when Parla can't read the saved key. Before, it said **Key stored in Keychain.** even though cleanup was failing.
- Errors in AI Cleanup now show as an orange warning, not small gray text that was easy to miss.
