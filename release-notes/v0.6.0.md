Parla now installs its own updates. When a new version is out, the menu bar menu says **Install Update**: one click downloads it, checks that it's signed by the same developer, swaps it in, and reopens Parla. It never does this in the middle of a dictation; it waits until the text has landed and your clipboard is back.

## Install

1. Download **Parla-0.6.0.dmg** below.
2. Open it and drag Parla into Applications.
3. Open Parla from Applications.

Runs on Apple silicon and Intel Macs, macOS 13.3 or later.

## If you're upgrading from 0.5.0

Replace Parla in Applications with the one from the DMG. This is the last time you'll do it by hand: 0.5.0 only knows how to open this page, and from 0.6.0 on, updates install from the menu. Microphone and Accessibility permissions carry over.

## New

- **Install Update vX.Y.Z** in the menu bar menu installs a new version and reopens Parla. If Parla can't replace itself, for example because it's running straight from the DMG, the item opens the release page instead.
- **Check for Updates…** checks right away and tells you if you're up to date. Parla also checks once a day while it's running, not only when it starts.

## Fixed

- The small idle pill no longer blocks clicks around it. Before, an invisible area many times its size caught clicks meant for the Dock or the window underneath.
- The pill moves back to its edge when you plug in or unplug a display or change the resolution, instead of staying where the old layout put it.
- The pill keeps its rounded capsule shape while it grows and shrinks, instead of briefly turning into a square-cornered box.

## Building from source

Still supported: `git checkout v0.6.0 && scripts/make-app.sh && open Parla.app`. A build from source can't install updates itself, since it isn't signed with the release's Developer ID, so its menu item opens the release page.
