# Pinned local recognition source

`vendor/whisper` contains upstream CPU sources (unmodified except one security patch, below), headers, CMake modules and licenses from whisper.cpp **v1.9.1**, revision `f049fff95a089aa9969deb009cdd4892b3e74916`, including its in-tree ggml. Upstream archive SHA-256: `279af4ce60dbf397362868f3bacc75b56a4332ac2541cae155070093f6aaf0e3`. See `source-manifest.json` for per-file hashes; licenses remain at `vendor/whisper/LICENSE` and `vendor/whisper/ggml/LICENSE`.

`python3 android/native/prepare-source.py` reproduces the source from the exact revision and verifies the archive before extracting. It downloads source only, never a speech model. The script leaves its verified source archive in this directory; the implementation session removed its own archive after extraction. GPU backends, tests, examples, models, tooling and other unrelated trees are omitted. Do not edit vendored source to implement app policy.

Gradle pins SDK CMake 3.22.1 and NDK 27.1.12297006 (r27b). `CMakeLists.txt` compiles a static CPU backend into `libparla-whisper.so` for arm64-v8a and x86_64, with armv8-a / baseline x86_64, no host-native march, OpenMP, GPU, curl, server, examples or upstream tests. Flexible page sizes and a 16KiB linker maximum-page-size are enabled. Actual packaged ELF alignment and Android loading still need a native link/package/device check.

JNI exchanges standard UTF-8 byte arrays with Kotlin; it never uses JNI Modified UTF-8 for speech. Registry IDs address shared cancellation tokens, never native pointers. Context, PCM, strings and abort userdata live until actual native return. Abort only reads a native atomic. Native init is not cancellable. Kotlin revokes delivery immediately and keeps a process-owned executor barrier through actual exit before another init/decode/model mutation. Contexts unload after each recognition. All JNI entrypoints contain exceptions.

Vocabulary prompt: the fourth `recognize` argument is not a finished prompt. Kotlin sends the byte-admitted terms (`VocabularyHints.asrTerms`, at most 2048 UTF-8 bytes) in saved priority order, one per line. Selection is native because only a loaded context has the model's tokenizer: whisper keeps just the last `whisper_n_text_ctx/2 - 1` prompt tokens (223 for 448), so an over-long prompt would silently drop the highest-priority terms. After init, `bridge_policy.h` `select_prompt` keeps whole terms that fit that budget, counted with `whisper_tokenize` (never `whisper_token_count`), and joins them with `", "`. `bridge_policy_test.cpp` checks it on the host against the shared `promptBudget` fixture vectors.

After Gradle CMake configuration, `python3 android/native/check-compile.py` runs each generated translation unit through its pinned NDK compiler with `-fsyntax-only`. This checks both ABIs without linking/assembling or loading a model. It is not a native execution test.

Loader bounds patch: users can import their own model file, so `src/whisper.cpp` carries `whisper-loader-bounds.patch` (every change is marked `// parla:`). The model loader, and the VAD loader's tensor loop, now fail cleanly (NULL context) on: hparams outside real whisper models (vocab 51864–51866, matching text/audio state, 1–64 layers); mel filters other than `n_mels` x 201; a vocab larger than `n_vocab`, or a word over 1024 bytes; tensor `n_dims` outside 1–4, a name length outside 1–128, an out-of-range ggml type, a dimension of zero or less, or an element count that overflows; and a truncated file at any variable-length read, including tensor data. `prepare-source.py` re-applies the patch and checks the `patched` hash in `source-manifest.json`; `files` keeps the upstream hashes. `sh android/native/loader-bounds-test.sh` builds the CPU loader on the host and checks crafted files: they must be refused, and real models given in `PARLA_REAL_MODELS` must still load. Against unpatched v1.9.1, `n_dims=99` segfaults and an oversized vocab hangs.
