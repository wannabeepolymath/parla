# parla for Android — local speech replacement

Native Android floating dictation control, foreground PCM capture and guarded Accessibility insertion. **Keep Gboard selected.** No custom keyboard or account is required. This source replaces the old cloud transcription core using current `Sources/ParlaCore` policy. It does not describe the historical 1.2.0 APKs.

1. Complete microphone, overlay and text-insertion permission setup.
2. On **Models**, explicitly Download / Pause / Resume / Discard a model transfer, then Select the verified model. Durable private checkpoints recover as paused after process death; nothing resumes automatically. The last usable installed model survives transfer failure/cancellation. Base English is the default selection; nothing downloads automatically. Small English is also English-only. Large v3 Turbo is multilingual. File sizes are 147,964,211 / 190,098,681 / 574,041,195 bytes; memory requirements are higher and device performance is not qualified yet.
3. In **Output settings**, choose cleanup, raw, or a saved rewrite/translation preset. Cleanup-off still applies local snippets and literal replacements. Whole-utterance snippets are locked locally. Raw bypasses all text policy except final destination field shaping.
4. Optional **API connection** configures text cleanup only: Anthropic (desktop default Haiku 4.5) or an HTTPS OpenAI-compatible endpoint with an explicit model ID. No audio upload exists. API keys are encrypted and bound to the canonical provider endpoint. Legacy encrypted keys need an explicit reviewed Save to bind them. Apple Intelligence is unavailable on Android.
5. Show the parla control from Home, return to a non-sensitive text field, then tap/hold to record and finish. Original node, text, selection and generation guards are retained. A write is one-use; uncertain writes are never replayed. There is no automatic clipboard fallback.

History defaults to 50 entries (configurable 1–1000). Disabling new history preserves saved text; Clear is separate. Original/result controls, explicit history retry proposals, share and plain-text/Markdown file export are wired. One transient original/result is retained in RAM for five minutes with a combined 64KiB limit, including insertion outcome/uncertainty. Process death clears RAM recovery. **Recovery audio is separate from text history.** New installs default to retaining failed/interrupted completed captures for seven days (configurable 1–30), with conspicuous setup/privacy disclosure; schema 1/2 Android installations migrate with recovery off until opt-in. Storage is private and excluded from backup, limited to 300 seconds per WAV and 128MiB / 128 files total. Successful ordinary dictation disposes audio even if later cleanup fails; canceled/private sessions are purged after readers exit. **Settings → Recovery audio** provides local Play/Stop, Retranscribe/Cancel with frozen current settings, raw-text preview, Copy, explicit Save to history, Delete and Clear. No recovery provider call, cleanup or editor insertion exists. History-off prevents Save until history is explicitly enabled. Recovery retranscription keeps its source until Delete/Clear or retention expiry, even after success/Save. Leaving the screen clears its preview; the retained source can be retranscribed after navigation or recreation.

Dictionary edits preserve saved priority; Move up / Move down controls send that order to local ASR (2048 UTF-8 bytes) and cleanup (8192 bytes), with a 256-byte per-hint limit. Exact-app profiles can override cleanup, style, language, local model, text model and priority vocabulary. Site profiles require trusted URL metadata unavailable here, so no screen scraping is used. The native shell and visual assets remain; old category-specific styles and editor-context upload are removed.

Unreadable local settings block writes and provider work. **Settings → Data recovery** offers reload and explicit JSON repair, preserving a dated private copy of original bytes. Failed writes do not publish unsaved state. Package identity, data filenames, keystore alias and backup exclusions remain intact; do not uninstall/reset to migrate.

See [implementation and qualifications](docs/DESKTOP-REPLACEMENT.md), [text provider contract](docs/API-CONTRACT.md), and [native source pin](native/README.md). Historical evidence/releases remain under their original paths. Source version is `1.3.0-dev` / code 4; this session did not assemble or produce an APK.

Focused verification uses the existing Gradle wrapper, SDK, NDK r27b and CMake 3.22.1. The implementation's test/lint/native-check commands and results are recorded in `evidence/desktop-replacement/`. No models, credentials, paid/live provider calls, device/emulator/browser sessions, publishing, commits or pushes were used. Native syntax checks do not prove packaging, model loading, JNI execution, transcription quality, Android UI behavior or 16KiB ELF loading.
