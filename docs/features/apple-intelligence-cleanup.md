## Supported actions and result policy

Ordinary dictation and ordinary automation share the existing cleanup factory, prompts and Pipeline. Raw ASR, cleanup-off local rules and exact whole-transcript snippets retain their earlier behavior without entering the local model. A failed ordinary request returns raw text through the existing literal replacement policy. It never switches to a network provider.

Saved rewrite presets require a deliberate **preserve source language** confirmation in the preset editor. Legacy presets default unconfirmed. Confirmed rewrites use the same intentional-transform path for dictated source, selected text and reviewed history retry. Translation presets and unconstrained spoken commands refuse before local session construction. They preserve the existing source/failure behavior, without ordinary snippets/replacements or a remote fallback. Intentional results are trim-only, preserve quotes/formatting, and retain the existing `max(2000, 6 × source characters)` ceiling. Ordinary results retain their sanitizer, nonempty, floor and ceiling guards. None of these length policies establishes semantic fidelity.

## Conservative language and resource policy

Admission is probabilistic and uncalibrated. User declaration is intent, not evidence. A fresh, request-confined, unbiased `NLLanguageRecognizer` supplies each observation. Require a leading hypothesis ≥0.95, runner-up ≤0.05, at least 24 Unicode letters and four whitespace-separated words, and refuse code-like delimiters `{ } [ ] = < >` / backtick / backslash. The whole surface and every letter-containing sentence/line (split on `. ! ?` and newline) must agree. Surfaces over 240 characters also use overlapping 240-character windows, stride 120, including the final tail. Short fragments refuse rather than being skipped. Source, selected source, all configured dictionary/snippet prompt surfaces and returned text must agree with the declared source/output language. Saved instructions may use another independently confident, runtime-supported single language. English built-in instructions, app locale, declaration, detected language and intended same-language output all require runtime locale support. No hardcoded marketing language list, declaration-biased classifier, English translation, hint dropping or unchecked long tail is used.

Unknown, short, ambiguous, mixed, unsupported or disagreeing evidence refuses the whole request. Names, code and romanized or mixed Hindi-English can be refused. This policy accepts false refusals and does **not** prove every mixed word is excluded. Native monolingual/mixed/romanized Hindi-English and offered-language quality require separate qualification.

Source plus instruction/selection is at most 8 KiB UTF-8, complete system plus user prompt 16 KiB, and response 32 KiB before existing result guards. Rule contributions are bounded incrementally before building another prompt; the entire request refuses when configured hints cannot be retained. No prefix truncation, segmentation or token-fit estimate. Byte caps do not establish token fit. The guarded FoundationModels adapter creates a fresh session with default guardrails, no tools/history, greedy sampling and `maximumResponseTokens: nil`: successful capped responses lack a qualified stop reason. Context/safety/assets/rate-limit/decoding/unknown errors become fixed finite reasons; no raw framework context, refusal explanation, extra generation or network retry.

## Ownership, settings and history

The 15-second **monotonic logical acceptance deadline** starts at actual request admission; equality is expired. Expiry permanently rejects late text and requests cooperative cancellation. Cancellation can precede worker handle installation. The caller still awaits actual generator exit and cancels/joins its watchdog before authorized ordinary fallback or releasing the existing processTask barrier. This is **not** a hard 15-second return or native-kill guarantee. A noncooperative model may delay graceful quit indefinitely. Discard/quit revokes publication, so neither generated output nor raw fallback can be published/saved from an old operation.

Local history retry freezes settings/rules/typed local access, not readiness or a session, and bridges once onto the app's existing serial chain with ASR, Safe Start and canceled-capture work. Missing app scheduling refuses. Canceled-before-dequeue settles from queue completion. Preview is memory-only; Save is explicit and conditional on the source version/history permission. Failed Save stores the retained result on retry without another generation. Changed/deleted sources become copy-only. Provenance distinguishes on-device generation from deterministic `localOnly`; token counts/cost remain unknown and diagnostics report local response attempts separately from HTTP requests.

Automatic selected-local startup, physical/selected entry, Hub refresh and live eval defer unrelated legacy key migration. No-op/load/status/Recheck/request preserve the entire original settings file. Genuine local settings edits/vocabulary imports use an authoritative locked preserving writer: legacy credential values and network endpoint binding remain, while new inline values, stale snapshots, endpoint rebinding, corrupt/recovered state or failed writes refuse. General Codable/portable export remains credential-free. The separately labeled **Migrate saved network credentials** action deliberately retains B07's both-scope add-only/readback/compare/conflict behavior. Switching back to a network provider follows that policy. Inactive model/base/environment configuration is retained; profile model overrides do not rename Apple's system model.

Shutdown/restart closes local admission before drain, revokes old publication, retains actual exit and permits only fresh work after canceled/rejected intent.
