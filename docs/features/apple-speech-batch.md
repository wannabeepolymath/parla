# Optional Apple Speech batch recognition (partial source qualification)

Whisper remains the default. Apple Speech is an explicit optional engine in General and saved profiles. It requires a bounded explicit locale whose identifier exactly matches a supported system locale. There is no current-locale guess, automatic language detection, or silent regional substitution. This slice does not offer equivalence proposals. Unsupported or invalid explicit configuration refuses recognition; it does not fall back to Whisper. Missing/null global engine fields retain Whisper compatibility. Missing/null profile engines inherit. Legacy profile Whisper model/language overrides under Apple require an explicit Whisper engine or replacement Apple locale. Saved Whisper path/language and dictionary words survive engine changes.

The General speech controls and the early Safe Start page share Prepare language, Cancel, Recheck and Release Parla reservation actions. The profile editor reaches that same owner. Save profile/configuration edits before preparing. Prepare explicitly permits Apple-managed language downloads/updates and reserves a language for Parla; it performs no microphone capture or inference. Recheck only observes readiness. Selecting an engine, startup, recognition, automation, tryout and recovery never reserve or install assets. Recognition requires an explicit Prepare-established reference even for preinstalled assets, then checks current runtime eligibility, exact locale, installed module/locale and reservation again.

The app stores a private atomic bounded record in the new `Parla-apple-speech-reservations/v1` Application Support namespace (32 locales, 16 KiB). Durable intent precedes reservation mutation. Ownership is separate from prepared state. An already-present reservation or a false reserve result does not grant release authority. Corrupt records, ambiguous interrupted intent and persistence failure preserve reservations and refuse tracking authority. Restart reconciliation never installs/reserves automatically. Global, enabled profile and live handle/pass references protect shared locales. Release applies only to a known owned, unused reservation after actual work exits; it does not delete shared disk assets. The system's reservation capacity is queried at Prepare; there is no eviction policy.

The conditional macOS-26 bottom uses SpeechTranscriber and SpeechAnalyzer, with a fresh module, analyzer and AVAudioConverter per actual pass. Framework/compiler/OS guards and runtime device availability are separate checks. It negotiates the actual format and fails conversion as a whole on error, without original-buffer fallback. Input is the existing finite 16 kHz mono Float capture (maximum 9,600,000 samples), source chunks are at most 16,000 frames, each output buffer at most 1 MiB, with a pull sequence and one app-pending output. Transcript acceptance is bounded to 1 MiB UTF-8 and 10,000 events. Rational analysis time and declared converter priming uncertainty are accounting evidence, not forced alignment or word timing.

Only final batch results are authoritative. Collector, conversion, input-accounting and finalization failure discard all fragments. Phrase spacing is preserved, exact duplicates are idempotent, and invalid/retrograde/conflicting/volatile results refuse the whole operation. Completed empty remains distinct from failure. Requested/resolved locale is separate from detected language; no detected language or confidence is fabricated. System asset revision is unknown, identity is session-fresh, and no Apple analyzer becomes a reusable Whisper resident.

Words apply to cleanup only. Apple passes never build/send Whisper vocabulary prompts or confirmed-prefix context. Explicitly required initial prompts refuse. Apple shadow streaming, progressive preview, window shortcuts and synthetic silence warmup are unsupported; final recognition uses the full original PCM. Undo Canceled Capture (B57) refuses Apple before offer/audio retention. Ordinary, command, dictated preset, result-only automation, tryout and recovery use the existing factory and output/security/storage boundaries. Text-only operations and existing offline eval branches do not gain ASR.

Recognition has a 60-second monotonic logical acceptance limit and Prepare a 180-second observation limit from actual admission; equality expires. Limit/cancel revokes publication and requests cancellation, then the queue retains native work, collector, cancellation task, observers and leases until actual exit. These are not hard-return or instant-stop guarantees. Cancel cannot prove OS download/network activity stopped; macOS may retry its initial attempt later. Progress is a bounded measured/indeterminate scalar at at most four publications per second, never fabricated bytes or readiness evidence. Rendering uses cached Apple state.

Apple admission/drain participates in actual quit and restart independently of catalog Whisper Safe Start (B53) and local cleanup (B22). Restart rejection/failure releases only restart reservations, preserving independent quit intent. A canceled quit reopens Apple admission only for deliberate new work. Safe Start remains saved and applies only to its catalog Whisper construction/explicit warmup contract.

No Speech authorization prompt, entitlement, usage key, packaging resource, deployment or dependency change is introduced. Existing microphone permission remains. Native Speech/audio, real assets, device eligibility, offline behavior, download retries, cancellation latency, format/priming behavior, human quality and performance, old-OS/Intel launch/link/weak-import and old-SDK/compiler packaging remain unqualified. B23/B31 remain PARTIAL; the source-reviewed count stays 22. This work makes no quality, performance, completion or default-engine recommendation.
