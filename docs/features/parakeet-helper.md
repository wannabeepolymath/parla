# Optional Parakeet source enabler (G1)

This is an inactive source enabler, not a working or qualified backend. Whisper
remains the default, with the root tools5.9/macOS13.3/Intel package unchanged.
A manually saved Parakeet selection is retained and finitely unavailable. No new
selector, Install/Prepare action, model downloader, helper producer or packaging
activation is provided. G2 must supply an immutable prepared installation lease;
G3 must supply an independently expected fresh trusted bundled product identity.
The default factory refuses before helper/native/model IO.

The real factory branch constructs ParakeetRecognition, the bounded parent driver
and a fixed app-owned arm64/macOS14 executable helper. The helper independently
compiles FluidAudio revision 503b4bd1bbf7220882de39fe8ae6716aae4132da with traits:[],
without a root dependency/import. One acquired session admits one batch worker;
there is no resident model or cross-acquisition/window reuse. Failed explicit
selection never falls back to Apple/Whisper or rewrites saved settings.

The local native chain sets ModelHub.offlineMode and logger console-off/.fault
before load/manager, then AsrModels.loadLocal(.v3,.int4,cpuAndNeuralEngine,
lowPrecisionAccumulation:true,encoderComputeUnits:nil),
AsrManager(ASRConfig(parallelChunkConcurrency:1),models:), fresh throwing
TdtDecoderState(await decoderLayerCount), array transcribe and awaited cleanup.
Prepare-load uses no synthetic inference. Requested compute is not observed ANE
assignment. The invoked TDT source has no direct print/fault call; its debug/info,
warning/error messages are below the configured threshold. Logger stderr-failure
print paths require console routing, which is disabled. Parent stderr is bounded
and discarded. CoreML/system/operational logging still needs native privacy
qualification. No general loader/download/recovery/compiler/cache purge is used.

The canonical contract and shared executable vectors are
fixtures/parakeet-helper-v1.json. Both independent packages compile the identical
small wire codec. Closed version/kind/length checks precede payload allocation;
PCM is finite mono16k Float32 [-1,1], <=9,600,000 samples, <=64KiB payload per
frame and one pending frame per channel. Terminal records are <=1MiB encoded
UTF8, one terminal plus complete input, EOF, exact identities and actual zero exit.
Unknown/truncated/trailing/duplicate/wrong-identity/nonzero-exit results fail the
whole pass. No transcript prefix is salvaged. Identity binds SDK/protocol/adapter,
helper/source/resource expectations, model revision/precision/manifest/integrity
strength/requested compute, OS scope, session/request and physical worker nonce.

Control stdin, framed stdout, discarded stderr and FD3 PCM are separate pipes.
The native parent uses fixed-path posix_spawn, explicit dup/close actions and
CLOEXEC-default; no shell/PATH/settings code path or provider environment. A single
serialized IO/exit queue uses nonblocking bounded IO and owns the child PID,
waitpid(WNOHANG)/EINTR and TERM/KILL escalation. Signal authority retires before a
reaping poll can make the PID reusable. Unknown exit remains owned/closed.
Handshake5s/load180s/batch120s logical monotonic limits expire at equality; cancel
grace2s precedes TERM, then another2s precedes KILL. These are acceptance/ownership
policies, not measured stop or runtime guarantees. Task cancellation revokes
publication; actual exit plus all IO/watchdog joins precede client/PCM/lease/queue
return. No queue abort slot is overwritten. Helper control-EOF handling is admitted
before model entry and invokes process self-exit independently of blocking load.
No process boundary, offline flag or empty environment is an OS network sandbox.
