# Import one PCM WAV

Open **Import Audio** in the Hub (also available before microphone onboarding), choose one file, then **Start**. Choosing a file checks metadata and holds a read-only descriptor; it does not read samples or load recognition. Canceling the picker preserves the current selection.

Supported input is a complete, regular, locally resident RIFF WAV: mono, signed 16-bit little-endian PCM at exactly 8, 16, 22.05, 24, 32, 44.1 or 48 kHz, 0.4–600 seconds, no larger than 20 MiB. Symlinks, aliases, cloud sources, nonlocal volumes, unsupported rates, other channels/codecs, malformed files and over-limit files are refused. Convert other formats outside Parla. Both limits apply together: a 48 kHz clip reaches the byte limit at about 218 seconds before header overhead. The 16 kHz path retains its exact strict decoder; other supported rates use one system PCM converter through full source and drained output EOS. Unsafe conversion refuses the entire job without fallback, padding or truncation. The entire accepted PCM extent reaches one raw final recognition pass. No prefix is reported as a complete import.

Start uses valid saved **global** engine, model, language and dictionary settings. Finish saving pending settings first. Import does not request microphone/accessibility permission, install assets, switch engines, run cleanup, insert into another app or enroll audio in a corpus. Existing engine preparation and availability gates still apply.

Review the raw transcript and transient source/conversion facts (source rate/frame count, output frame count and finite overshoot clipping), then explicitly **Copy** or **Save**. Save requires history to be enabled. A failed Save retains this review for **Retry Save**, which retries storage only. A successful Save remains latched even if its history row is later deleted. Saved entries use result time, no source path or app label, and the existing history text/Markdown export and separately explicit cleanup retry actions.

Discard, page/window exit, relevant recognition/preparation changes, observed invalid settings, secure-input evidence, quit and restart revoke the review permanently. Repairing settings or canceling quit does not restore it. Choose a file again for a fresh job. Cancellation waits for the actual reader/recognizer to exit before another job can enter. Ordinary Start never writes, copies, stages or deletes the original. After complete read/validation the descriptor closes and recognition uses an immutable memory snapshot; later source-path edits are not watched.

For ordinary Start, source facts live only in the current review and are not saved in History or diagnostics. The output PCM payload limit is 38.4 MB; active app conversion buffers hold at most 49,152 bytes of Float payload, excluding the encoded snapshot, output vector, native allocations and object overhead. These are not total memory or timing guarantees. Ordinary Start has no restart persistence. Neither mode adds batch/video/general-codec import or an automatic recognition queue. Native file-panel/security-scope/file-provider/accessibility behavior, real installed-backend/offline operation, hardware resource behavior and consented human recognition quality remain separate qualification gates. B40 remains partial.


## Saved private imports

**Keep a private copy and transcribe** is a separate, disclosed action on the same page. It retains the exact encoded bytes from the existing complete validated read, including accepted RIFF ancillary chunks. It never reopens the original to stage a second snapshot, moves or deletes it, stores a bookmark, or reencodes Float samples. The existing serial queue stages the source before it enters preparation, factory construction or raw recognition. Registered source and result IO leaves the main actor while keeping its actual-exit hold. Ordinary Start and experimental timed Start remain transient. Saved imports store raw text only.

The private copy and raw result have a fixed seven-day logical expiry from initial admission. Retry never renews it. Physical removal happens when Parla can execute safe maintenance after actual readers, conversion, recognition and IO exit; app-off time, bad clocks and storage failures can delay removal. History off does not prevent this independently consented copy. Cancel transcription and closing a review retain committed source/results. Delete removes this saved job, leaving independent History rows and exports intact. A failed first Delete-intent write revokes this process's authority but is not durable Delete acceptance and cannot guarantee non-reopen after a crash with no persisted evidence. The UI reports that private files remain.

The list is a metadata projection. Eager registration is separate from metadata completion: pending or unavailable metadata refuses saved admission and export protection; registered saved IO also temporarily refuses export protection rather than waiting on its storage lock. Readiness never blocks the main thread. Launch/bootstrap, rendering and Refresh never run ASR. Existing valid inactive expiry is a separate finite maintenance pass at launch, before admission, after execution borrows exit and on explicit Refresh. Selecting **Open raw review** verifies bounded stored UTF8, hash, identities and linkage and completes storage qualification without reading/decoding audio or loading a model. A saved result starts unverified on restart; a missing source can still have independently verifiable raw text. Running/queued work becomes interrupted and requires **Retry transcription**, which freezes fresh valid saved globals and uses only the held, verified owned source. Invalid clocks, settings, changed storage or stale authority refuse rather than select a fallback.

**Copy** and **Export text…** are explicit. TXT contains exactly the selected raw UTF8, with no private metadata. Export freezes bytes and review identity before the panel, rechecks settings/drafts, security, preparation, expiry and job/result authority after it and immediately before the synchronous writer. All Hub writers—History, diagnostics, vocabulary, transient WebVTT/SRT and saved TXT—also protect the saved root/known flat members, retained originals by lexical/resolved paths and device/inode, and available current transient original identity. Hardlinks remain protected after an original changes in place. Existing settings/history/recording protections remain. A missing saved root has an empty added projection; existing unknown, contended or unreadable storage refuses incomplete protection before even an injected writer. This adds no model/download/preparation-tree inventory.

A failed result write can keep one current raw review in RAM: **Retry Save result** writes those same bytes/result identity without source read, conversion, acquisition, recognition or provider calls. Revocation/restart loses unsaved RAM text. **Retry transcription** is a different explicit native attempt. Prior accepted raw results survive failed or canceled retries and require fresh explicit Open to review again. Export disk failure permits another explicit export of the current bytes.

History remains text-only and independently optional. Save requires a committed verified result and current authority. Persisted saving intent precedes `appendReviewed`; failure to record intent prevents the append. Successful append sets a RAM latch before receipt IO. **History saved; Retry record status** retries the receipt only, including if the History row was subsequently deleted. A restarted unresolved intent with an exact row may resolve saved; an absent row cannot distinguish append failure from later deletion, so another append for that result is forbidden. Copy/export remain available. No generic pending-History escape, automatic append, schema change or row resurrection is introduced.

Limits are one admitted saved transaction, ten allocated slots including incomplete/deleting jobs, 256 MiB logical charged bytes plus reservations, a 20 MiB source under the existing duration/rate grammar, a 1 MiB raw result, and one additional candidate/retired result globally. The aggregate ledger and its replacement are each bounded at 64 KiB; owner and each deletion intent at 4 KiB; the namespace refuses its 65th entry. Checked revisions, closed field/schema caps, 65,536 syscall work credits, 128 EINTR retries, cooperative 30-second IO checkpoints, and advisory 512 MiB free headroom plus remaining write reservations bound work. A blocked syscall/native constructor is never forcibly preempted, and none of these is a physical disk, memory or latency guarantee. No eviction occurs.

Storage uses a separate private `Parla/saved-imports` namespace on local APFS/HFS+ volumes, descriptor-walked safe parents, owned 0700 root/0600 same-device singlelink members, conservative ACL classification, a lifetime advisory lock and a same-process identity registry. Unknown/future/corrupt/partially bootstrapped state is preserved and unavailable; there is no repair/reset/sweep or chmod/chown adoption. Original paths are private destination-protection metadata only, never read/delete authority. File sync, checked close, independent descriptor/hash verification, bound-root rename and directory sync precede current-process acknowledgement. Required failure remains unavailable/uncertain. This is checked process-crash publication, not mandatory `F_FULLFSYNC`, power-loss qualification, hostile same-UID protection, encryption or secure erase.

Delete revokes runtime authority, records/syncs a generation-bound intent, aborts and actually joins every borrower, unlinks only matching owned members, syncs payload absence, then persists a deleting/resources-retired authority barrier while the slot stays charged. It next removes and syncs the intent, then removes and syncs the allocation to release its quota. Every intermediate deleting state denies source, result, transcription, History association and saved export authority, including after restart when the intent is already absent. Retained identity facts serve cleanup and protection only. Slots/reservations stay charged until settlement. Failures remain visible and may require explicit Retry Delete; no original cleanup occurs. Eager saved IO participates in real quit/restart/updater reservation/drain/readiness/release even before a Hub exists or with native preparation disabled. Accepted storage uncertainty vetoes readiness. Canceling quit never restores old reviews or resumes recognition.

This source candidate is unreviewed. Synthetic tests and fake-native connections do not qualify real panels/security scopes/file providers, installed backend/assets, native playback/recognition quality, supported-device behavior, abrupt-process/power-loss behavior or a physical erasure deadline. B40 stays PARTIAL; B43 deferred; B47 conditional PARTIAL; B02 human gate open; B28 deferred; reviewed count 22.


## Experimental native timing

Ordinary **Start** remains the default raw path. **Start with experimental timing** is a separate choice for this job only. It requires Whisper and an original strict mono 16 kHz PCM WAV. A supported source at another rate may already be converted by the existing reader, but is refused before timed recognition. Multilingual models require a valid selected language; Automatic/invalid language refuses. English-only models use English. Unsupported clients and the exact native model class that forces timestamps off refuse, with no backend fallback.

Timed mode makes exactly one full `whisper_full` call on the immutable complete PCM, without language probing, app retry, window assembly or timing repair. Native temperature fallback and internal windows remain enabled. Timing-enabled recognition may produce different text from ordinary Start. The current review separately shows native cue text/ranges and the legacy marker-filtered raw transcript; no cleaned, replaced or translated text receives timing. Native ranges retain gaps, equal starts and overlap. They establish neither speaker identity, complete recognized speech coverage nor acoustic accuracy.

Explicit **Export native WebVTT…** or **Export native SRT…** uses only this current transient review. History may be off; Save still requires it. Copy, Save, Retry Save and the saved latch after History deletion keep their text-only behavior. Timing is never stored in History and disappears on Discard, reselect, page/window exit, revocation or restart. Saved text cannot recover it. Nothing is automatically copied, saved or delivered.

The source contract targets whisper.cpp v1.9.1, commit `f049fff95a089aa9969deb009cdd4892b3e74916`: integer 10 ms ticks from supplied PCM zero, including internal window offsets. Actual linked-binary provenance and backend/acoustic qualification remain open; this source candidate is not approved. Timestamp generation, translation/detection/VAD/token timestamps/DTW and wrapping options are set explicitly for this finite path. All contexts remain outside VAD. Invalid/missing clocks, negative/reversed/retrograde/out-of-source intervals, native extraction errors or observed abort refuse timing as a whole, with no clamp, sorting, prefix salvage or guessed cue. Complete independently valid bounded raw text may remain available after a timing-only refusal.

Extraction permits at most 10,000 native segments and 1 MiB total native UTF8, using bounded null scans and strict UTF8. WebVTT output is UTF8 without BOM, fixed header, numeric cue IDs and exact integer millisecond ranges, capped at 8 MiB including wrappers/escaping. Native `&`, `<`, `>` are escaped once (including arrows/tags/entities). CRLF/CR become LF only in export. Empty/edge/space-tab-only lines, C0 except tab/LF, DEL/C1, U+2028/2029 and explicit bidi direction controls refuse under a deliberately stricter product policy. Ordinary RTL logical order, joiners, combining marks and emoji remain intact; NOTE/STYLE/REGION are literal payload words. No voices, styles, word timing, confidence, diarization, converted-source or live-window alignment is offered.

SRT output is UTF-8 without BOM, LF only, with numbered cues starting at 1, `HH:MM:SS,mmm` ranges (refused at 100 hours), and a blank line after each cue. The same 8 MiB cap includes every output byte and framing. Cue text is written unchanged apart from CR/CRLF→LF normalization. SRT has no escaping, so Parla refuses the whole SRT file for any cue containing `< > { } \` or an entity-shaped `&…;` matching `&[A-Za-z0-9#]+;`; a plain ampersand is allowed. WebVTT stays available. Neither file contains speaker names, voices or styling; readers may trim leading/trailing spaces; player rendering is unqualified.

Export freezes exact bytes and the job/result identity before destination selection, rechecks security/configuration/draft/preparation/current-review authority afterward and immediately before the synchronous B42 atomic writer, and protects original audio plus settings/history/recordings and their lexical/resolved aliases. Wrong extensions refuse even with an injected writer. Cancel writes nothing. Disk failure keeps the review for explicit export retry without recognition. This does not claim hostile cross-process filesystem race protection or qualified native/file-provider panels. B47 remains PARTIAL/uncompleted; binary, native UI, player and consented human timing qualification remain open.
