# Intentional transforms and dictation output

In **Output & Presets**, choose Normal cleanup (default), Raw ASR, or Selected preset. Presets start empty and contain a stable ID, name, and either a rewrite instruction or explicit translation target. Select a preset separately. Deleting the selected preset leaves a visible missing selection; neither dictation nor the shortcut silently picks another one. Invalid or missing presets refuse with a visible error.

Normal cleanup preserves the speaker's language. Cleanup off still applies the existing local snippets and literal replacements. Raw ASR bypasses AI, endpoint warming, snippets and replacements. All dictation modes retain audio/minimum-speech guards, secure-field exclusion, safe pending delivery, single-line/browser/terminal constraints and the capture-time history policy.

Selected preset transforms only the final ASR transcript. Its mode, selected ID and preset configuration are frozen at capture start. App/site profiles retain the separate capture recognition and landing output policy: effective cleanup model and vocabulary follow the winning output profile, while provider, endpoint and credentials remain global. A cleanup-off output profile refuses intentional requests without constructing or warming a provider. No provider switching or model downloading occurs.

In **General → Shortcuts**, optionally bind **Run selected preset**. It starts unbound and supports Change/Clear with the existing physical key serialization, collisions, trigger/reserved-key rules, repeat suppression and shortcut-recorder suspension. Invoke it while selected text is in the destination app. It captures the source and native destination before queueing work and uses no recorder, ASR or loaded local model. There is no Run button in the Hub. **Shift + push to talk** continues to accept a spoken transform instruction and now uses the same result and destination protection.

For all intentional requests, the explicit saved/spoken instruction precedes `<text>` in the user message. Everything after that delimiter through the end is source data, including embedded tags or instructions. Source data is never a system instruction. Results are trimmed only (quotes are preserved), must be nonempty and at most `max(2000, 6 × source characters)`, and never receive snippets or literal replacements. Provider errors have no automatic source/instruction fallback.

Selection replacement requires the same generation, safe focus, original process/window/field identity, unchanged selected text and released shortcut modifiers. Unverifiable/opaque field identity parks the result rather than replacing a selection. Ordinary pending dictation retains its existing destination guard and unknown-app fallback. A preset result uses the original destination's browser and single-line constraints at final insertion. After waiting up to one second for held shortcut modifiers, a still-held shortcut parks instead of emitting modified keystrokes.

When history is enabled, transform rows retain the original selected source/raw ASR as `raw`, the valid result as `cleaned`, and optional operation provenance (selection/dictation/spoken, preset ID/name, completed/parked/failed). Failed results retain the original source without fabricated cleaned text; valid parked results remain available to Copy. History shows the operation status and offers Copy source as well as Copy result. Legacy rows are unchanged. With history off, no transform row is written; undeliverable text is discarded with an honest status. Native secure dictation capture is still excluded entirely. Intentional provider usage is collected per operation, including billed unsuccessful responses, without changing unrelated live dictation metrics.

Vocabulary import/export does not include presets, output mode or shortcuts. `parla-eval` explicitly resets live output mode, presets and selection alongside the existing profile/style reset, keeping its pinned fixture contract.

Fake-client tests cover production request/reducer/probe seams and Hub → persistence → hotkey → request. Native AX field/window identity, shortcut routing, focus changes, actual paste acceptance, Hub layout and real rewrite/translation fidelity still require native qualification; no live model/provider qualification is implied.

Apple Intelligence supports only explicitly confirmed same-language saved rewrites in this slice. Existing presets default unconfirmed; confirm deliberately in the preset editor. Translation and unconstrained spoken instructions refuse locally, preserving source/failure semantics. Local requests use independent declared/detected language checks and never switch to a network provider. See [Apple Intelligence cleanup](apple-intelligence-cleanup.md) for budgets, logical deadline and pending native/human qualification.
