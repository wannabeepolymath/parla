## Why this file exists before it is needed

Dual-licensing requires the copyright holder to hold **all** the copyright.
Parla has no external contributors today, which makes this the cheapest moment
in the project's life to reserve the option — the alternative is asking every
past contributor for permission later, which in practice means the option is
gone. Epicenter has no CLA and consequently cannot ever relicense; this file
is the stub that keeps the door open, in the shape TypeWhisper uses.

Nothing here is exercised. There is no paid build of Parla today, and the AGPL
grant in `LICENSE` is unconditional and irrevocable for the code as published.
This file reserves a right; it removes none.

## If you contribute

Contributions are accepted under the same license as the file being changed
(AGPL-3.0-or-later for the app, MIT for `Sources/ParlaCore/`). By opening a
pull request you agree your contribution may also be offered under a commercial
license by the copyright holder. If a CLA becomes warranted, it will be added
before, not after, the first external contribution is merged.
